# Skystore - Интернет-магазин на Django

Проект интернет-магазина, разрабатываемый в рамках учебного курса. Проект будет дорабатываться на каждом уроке.

## Функциональность

### Реализовано в текущей версии:
- **Главная страница** - приветственная страница магазина
- **Страница контактов** - форма обратной связи с валидацией
- **Обработка форм** - отправка и валидация данных контактной формы

## Установка и запуск

### 1. Клонирование репозитория
```
git clone <url-репозитория>
```

### Установка зависимостей

```
poetry install
```

### Запуск сервера разработки

```
python manage.py runserver
```
